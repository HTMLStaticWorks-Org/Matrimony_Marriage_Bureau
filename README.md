# Sutram Website — Front-end preview

A responsive multi-page matchmaking website concept using the approved Sutram identity.

## Open locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, serve this folder with a local static server.
3. The Margarine typeface is loaded from Google Fonts and therefore needs an internet connection; a cursive fallback is provided.

## Pages
- `index.html` — Classic homepage
- `home-2.html` — Premium / concierge homepage
- `about.html`, `contact.html`
- `search-profiles.html`, `success-stories.html`, `membership-plans.html`
- `login.html`, `signup.html`, `dashboard.html`

## Included interactions
- Responsive navigation
- Light / dark mode with local preference persistence
- LTR / RTL layout direction with local preference persistence
- Search form navigation, profile filter feedback, contact form validation, login/signup front-end validation
- Member dashboard preview and navigation

## Important launch requirements
This is a front-end prototype, not a production matchmaking platform. It does not create accounts, authenticate users, store member profiles, perform real profile matching, send messages, process payments, verify identities, or securely enforce privacy/access controls. Those require a secure backend, database, authentication and authorization, audit logging, moderation workflows, consent management and appropriate integrations.

Before launch, replace the editable contact placeholders, approve actual plan prices/limits/terms, add verified business information, legal/privacy documents, and only publish member stories/photos with written consent. Do not treat the sample profile cards or dashboard counts as real members or live data.
